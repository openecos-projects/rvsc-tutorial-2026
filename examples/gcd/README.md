# GCD example

Tutorial fallback for participants who do not have their own RTL yet.
`rtl/gcd.v` is a single-file GCD design with `clk`/`reset` and a valid/ready
interface, matching the `ecc.toml` generated by `ecc init gcd`.

```bash
mkdir ~/ecc-demo && cd ~/ecc-demo
ecc init gcd && cd gcd
cp /path/to/rvsc-tutorial-2026/examples/gcd/rtl/gcd.v rtl/
```

Source: [`openecos-projects/ecc` `docs/examples/gcd/gcd.v`](https://github.com/openecos-projects/ecc/blob/main/docs/examples/gcd/gcd.v)
(Apache-2.0), originally generated from PyMTL and modified for OpenROAD tools.
